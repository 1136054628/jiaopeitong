# 教培通 · 教培行业手机工作台

一个**纯前端、无需服务器**的手机工作台（PWA），打开即用，可安装到手机桌面。
数据保存在本机浏览器（localStorage），可随时导出备份。

- 主色：白 `PANTONE 11-0601TCX` / 蓝 `PANTONE 286 C`（#0033A0）
- 适配手机，桌面浏览器打开也会自动居中成手机样式

---

## 一、功能一览

| 模块 | 包含 |
|------|------|
| 工作台首页 | 学生模块卡、老师模块卡、记录（消课/充值/工资）、报表（日/周/月/年收支） |
| 学生管理 | 学生档案（搜索/标签/添加）、消课、费用（报名/缴费/欠费/续费） |
| 班级管理 | 班级名册、班级运营（收支/续费）、结课管理（课时与费用汇总） |
| 课表 | 多维课表（学生/教师/班级）、排课调课、课时统计（日/周/月） |
| 家长沟通 | 沟通记录、批量通知、回访管理、反馈处理 |
| 老师管理 | 师资档案、课时课酬（自动核算+结算进度）、教学评估、工资统计 |
| 快速导入 | 数据导入（CSV/粘贴）、导入记录、一键导出备份 |

底部导航可快速切换 7 大模块；首次打开为空白数据，可直接录入或通过「快速导入」导入。

## 三、部署到 GitHub Pages（免费，推荐）

> 部署一次后得到一个固定网址，手机联网即可访问并安装。后续改动重新上传即可更新。

1. 注册 / 登录 [GitHub](https://github.com)。
2. 右上角 **＋ → New repository**，仓库名填 `jiaopeitong`，选 **Public**，点 **Create repository**。
3. 进入新仓库，点 **Add file → Upload files**。
4. 把本目录里的这些文件**全部**拖进去（`index.html`、`styles.css`、`app.js`、`manifest.json`、`sw.js`、`logo.svg` 以及 `icons` 文件夹），点 **Commit changes**。
   - 可把整个文件夹拖入上传框，GitHub 会保留 `icons/` 目录结构。
5. 打开仓库 **Settings → Pages**：
   - **Source** 选 `Deploy from a branch`
   - **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**。
6. 等待约 1 分钟，页面顶部会显示你的网址，形如：
   `https://你的用户名.github.io/jiaopeitong/`

✅ 用手机浏览器打开这个网址即可使用。

## 四、部署到 Netlify（备选，拖拽更简单）

1. 打开 [netlify.com](https://app.netlify.com)，登录（可用 GitHub 账号）。
2. 在 **Sites** 页面，把整个 `jiaopeitong` 文件夹**直接拖进**页面中间的虚线框。
3. 几秒后 Netlify 会生成一个随机网址，点进去即可用（可改成一个好记的名字）。

## 五、安装到手机桌面

### Android（Chrome / Edge）
1. 用 Chrome 打开部署好的网址。
2. 点右上角 **⋮ 菜单 → 安装应用**（或「添加到主屏幕」）。
3. 弹窗点 **安装**，桌面即出现「教培通」图标，点击直接全屏打开。

### iPhone / iPad（Safari）
1. 用 Safari 打开部署好的网址（**必须用 Safari**）。
2. 点底部 **分享按钮**（方框+上箭头）。
3. 向上滑动，点 **添加到主屏幕** → 右上角 **添加**。
4. 桌面出现「教培通」图标，点击全屏打开。

> 提示：安装后像普通 App 一样使用；若要更新内容，重新部署后刷新即可（Service Worker 会自动更新）。

## 六、数据说明与备份（重要）

- 数据存在**当前手机浏览器的 localStorage** 里，不上传、不联网同步。
- 以下操作会导致数据丢失，请务必先备份：
  - 清除浏览器数据 / 卸载 App / 更换手机或浏览器。
- **备份方法**：进入「快速导入 → 数据导入 → 导出全部数据（JSON）」，保存备份文件。
- **恢复**：当前版本为「导入/导出」轻量备份；如需完整恢复，可把 JSON 内容整体复制，或后续扩展「从备份恢复」功能。

## 七、本地预览（不部署也能看）

双击 `index.html` 即可在浏览器打开（数据保存、基本功能都正常）。
注意：**安装到桌面（PWA）需要 HTTPS 或 localhost**，直接双击文件无法“安装”，但能正常预览使用。

也可以在命令行起一个本地服务：

```bash
cd jiaopeitong
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 八、自定义

- **改配色**：编辑 `styles.css` 顶部的 `:root` 变量，`--blue` 即主蓝色。
- **重新生成 LOGO**：改 `make_icons.py` 后运行 `python make_icons.py`（需安装 Pillow：`pip install pillow`）。
- **改机构名**：首页顶部点机构名即可直接改名。

## 九、常见问题

**Q：为什么换了手机数据没了？**
A：数据是单机存储，不会同步。换手机前先「导出全部数据」备份。

**Q：能多人同时用、实时同步吗？**
A：本版是纯本地单机版，不支持多人同步。如需云端多人协作，需要加后端+数据库（可另行扩展）。

**Q：安装后图标没显示或白屏？**
A：确认是通过 HTTPS 访问（GitHub Pages / Netlify 都是 HTTPS）；iOS 请用 Safari 操作。
